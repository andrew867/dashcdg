dashcdg — bundled MP3+G sample library
=====================================

This directory contains paired .cdg + .mp3 tracks used for transmitter/receiver
testing (shuffle, seek, cold join, codec switches). The desktop TX and player
entrypoints scan here by default when no path is given.

Engineering note
----------------
These files exist so you can exercise the stack without hunting for media. If you
redistribute them outside your own lab, you are responsible for licensing.

Documentation
-------------
See docs/test/sample-media.md in the repository for release zip names and details.
