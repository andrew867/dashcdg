# Fork manifesto — why this exists

This repository is a **fork** of [AppleDash/dashcdg](https://github.com/AppleDash/dashcdg)
([andrew867/dashcdg](https://github.com/andrew867/dashcdg) on GitHub). The governing
question was never “should we?” — it was **“can we?”**:

- multicast MP3+G-style transport with **late join**, **snapshots**, and **bounded repair**
- **v4** on the wire by default, with enough codec variety to be embarrassing in a good way
- **Windows** builds that go from “works on my machine” to **USB sneakernet** trees with
  x64, x86, legacy P3, and **retro** (no GL) layouts
- enough instrumentation and docs that the next person does not have to read the tea leaves

If something is **possible** but **rough**, it still ships here behind a flag, a script,
or a README honest paragraph. If you need a quiet life and a vendor SLA, buy a black
box; if you want to **see the wires move**, you are in the right place.

For the boring index of specs and tests, see [`README.md`](README.md).
