# Atari ST YM archives (PaCidemo / aldn) — external references

Public **`.ym` dump / replay** culture on the Atari ST is unrelated to CD+G subchannel work, but it is useful **listening and format context** for badge **Audio lab** chiptune demos (square-wave PWM lab, not a YM2149 emulator).

**Primary index (curated “YM archives” landing):**  
[https://pacidemo.planet-d.net/aldn/index.html](https://pacidemo.planet-d.net/aldn/index.html)

That page states (paraphrased): the archives contain **more than 3800** tunes composed on Atari ST; **PC playback** is described as needing **StSound**; the first archive came from **Aura**, with many conversions by **Leonard**, **BDCannibal**, and **Frédéric Gidouin**, and long-term care attributed to **aldn** (re-records / re-loops). Contact listed there: **aldn@tiscali.be** (historical mail; treat as archival metadata, not a support contract for dashcdg).
